# 图层地图 0.4.1 · 导入与底图生命周期

> 日期：2026-11-26  
> 范围：Fandom 图片地图、Map Genie 瓦片地图、只图片/只点位包、底图替换与对齐、窗口、地图包管理。

## 0. 一句话

用户不再需要先理解 JSON、图片、名称三个内部字段：把一个包丢进来，自动识别、先给预览、确认后一次写入；底图是用户资产，任何时候都能换、能移除、能补。

## 1. 一个包一次导入

```text
┌─ 导入地图包 ──────────────────────────────────────────────────┐
│ 拖入 .zip / 整个文件夹，或分别选择：                          │
│ [选择 .zip] [选择文件夹] [选择 JSON] [选择底图] [选择瓦片夹]  │
│ 已选：JSON map.json · 底图 map-image.jpg · 瓦片 20 张         │
│                                                               │
│ Fandom 地图页面 URL [................................] [读取] │
│ ▸ 高级手动模式（JSON URL / 说明）                             │
└───────────────────────────────────────────────────────────────┘
```

- 原生 `<input type="file">` 只作为隐藏实现，不作为 UI。
- 按钮全部是真实按钮，旁边始终显示已选文件名/文件数量。
- 支持拖放 `.zip`、文件夹、JSON、图片；也支持一次选择整个包。
- 导入前先进入预览，不立即写库。

## 2. 自动识别规则

### 包结构

```text
my-map.zip / my-map/
├─ manifest.json          可选
├─ map.json               Fandom JSON
├─ mapdata.json           Map Genie mapData
├─ map-image.jpg          可选，Fandom 图片
├─ tiles/                 可选，Map Genie 瓦片
│  └─ {z}/{x}/{y}.jpg
└─ README.md              可选，跳过
```

### Fandom

- 读 `markers`、`categories`、`mapBounds`、`origin`、`coordinateOrder`。
- `coordinateOrder=yx` 时交换坐标；`origin=bottom-left` 时翻转 y。
- 自动找 `mapImage`：
  - manifest 指定优先；
  - 文件名精确/规范化匹配；
  - 包内唯一图片；
  - 多图时选最接近的，并在预览里提供缩略图选择。
- 名称优先级：manifest → 包名（非通用名）→ mapImage 文件名 → Fandom 地图。
- 本地包没有 Wiki 域名时：manifest → 绝对链接 → 包名关键词 → `forgottenrealms.fandom.com`，高级里可改。
- 只导入数据里真实存在的链接；没有链接时详情显示“源数据没有链接”，不按地点名伪造。

### Map Genie

- 读 `mapData.map.title` 作为名称；读 `mapConfig.tile_sets`。
- 自动选瓦片组：manifest 指定 → 本地文件匹配最多的组 → 第一组。
- 从 `tile_sets[0].pattern` 判断 `{z}/{y}/{x}` 或 `{z}/{x}/{y}`；pattern 缺失时用 bounds 推断。
- 无 bounds 的地图按 WebMercator 处理，不假装有像素边界。
- 瓦片可以只覆盖部分层级；预览显示覆盖范围和缺失数量，不阻止导入。
- Map Genie 页面 URL 不解析；粘贴时明确提示使用本地 `mapdata.json`。

## 4. 底图生命周期

### 导入时

- 可换本地图片（文件选择、拖放、粘贴）。
- 可从包内多张图里选；占位图会明确标记。
- 可移除；移除后仍可先导入点位。
- 只选一张底图时，允许先导入图片包，之后关联 Fandom JSON。

### 导入后

地图顶栏有一个当前底图缩略图；没有图时是虚线图框。点开：

```text
┌─ 底图 ─────────────────────────────────────────────── [×] ┐
│ [当前底图]                                      [查看大图] │
│ map-image.jpg                                              │
│ 1680×2400 · 861 KB · 包内图片 · 铺满地图                  │
│ 显示 [铺满地图 ▾]                                          │
│ [更换底图] [移除底图] [对齐底图]                           │
│ 底图只保存在本机，不会上传。                               │
└────────────────────────────────────────────────────────────┘
```

- 换图保留地点、链接、笔记；只重置对齐。
- 移除底图保留数据，可撤销。
- 重新导入同一个包时，手动换过/移除的底图会保留（`imageLocked`）。
- 包内多图只在导入预览里选择；导入后要换回包内另一张，重新导入同一个包即可。

### 对齐底图

换到裁切/比例不同的图片后，地点可能偏：

```text
┌─ 对齐底图 ───────────────────────────────────────────────────┐
│ 拖动图片对齐地点标记，滚轮缩放。 [重置铺满] [取消] [完成]     │
├──────────────────────────────────────────────────────────────┤
│              ● 地点标记固定，底图在下面移动                  │
└──────────────────────────────────────────────────────────────┘
```

保存的是图片在地图画布里的归一化矩形，不改 JSON，不改地点坐标。

## 5. 窗口

- 标题栏可拖动，八向缩放，双击标题栏复位。
- 最小尺寸 560×380；窗口宽度 <820px 自动紧凑：左栏收进“图层”，详情变底部浮层。
- 手机视口（≤640px）全屏，不套桌面浮动窗口。
- 位置/大小存 `localStorage`；移动/缩放不超出浏览器窗口。
- 导入弹窗自身滚动，不因窗口小而裁掉字段。
- SillyTavern 移动端 body 是 fixed 且可能形成零高 containing block；FAB、面板和弹窗都写显式 top/left/width/height，避免被算到屏幕外。

## 6. 地图包管理

- 列表：缩略图、类型、地点/分类/区域、包大小、文件数、缺底图/缺瓦片。
- 重命名（不改 id、地点、笔记）。
- 删除（不删除聊天里的地点笔记）。
- 更换底图；移除底图；查看原图。
- 重新选择瓦片文件夹；瓦片 URL 模板。
- 只图片包可以“关联 Fandom JSON / 地图包”；只点位包可以在底图浮层补图。
- 包元数据在 IndexedDB，聊天状态（笔记/链接/当前地点）在 `chatMetadata`，窗口几何在 `localStorage`。

## 7. 链接与说明

- 地点详情始终显示“链接来源”。
- 源数据没有链接时明确写“源数据没有链接”，不伪造。
- 只有点击“抓取”才请求链接正文；失败保留“打开”和“粘贴”。
- Fandom/Wikipedia 直接 fetch 常被 CORS 拦截，优先走 MediaWiki `action=parse&origin=*`；普通站点直连。
- 抓取到的正文可展开/收起，不截断内容。

## 9. 边界

- 不解析 Map Genie 网页 URL；只支持本地 `mapData`。
- 不做像素级裁剪/旋转/涂改；对齐只移动和缩放整张底图。
- 一个包只保留一张活动底图；不做多套底图变体。
- ZIP 支持 store/deflate 和基础 ZIP64；加密包和不支持的压缩算法会报错。
- 真正的数量上限是浏览器 IndexedDB 配额与内存；没有人为的瓦片/地点/说明/链接数量限制。
