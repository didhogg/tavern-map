# 图层地图 0.5.6 · 街道标签性能与加载隔离

> 日期：2026-11-26  
> 范围：修复 Tych Waterdeep 这类带 300+ 条街道线的包在低性能设备上打开时卡住的问题。

## 原因

0.5.5 的街道标签在每个地图移动帧中都会：

- 遍历全部 309 条街道；
- 把每条街道的全部折点（合计约 4,700 个）逐个投影到屏幕；
- 再为每个候选标签做碰撞检测。

在普通机器上这还可以接受，但在低性能设备、浏览器缩放或高 DPR 下，MapLibre 移动事件连续触发时会占满主线程，表现就是进入地图后黑屏、页面卡住。

另外 `loadPackage` 以前会先等待 MapLibre 和瓦片初始化完成，才渲染侧栏、顶栏和详情；初始化慢或网络阻塞时，整个窗口会先变成一块黑色区域。

## 修复

- 街道标签锚点和角度只计算一次，按街道 id 缓存；每帧只投影一个点，不再重算全部折点。
- 每帧最多绘制 120 个街道标签，主路和次路优先。
- MapLibre 正在移动时跳过街道标签绘制，等 `moveend` 后再画一次。
- `labelCellKeys` 增加有限值/空尺寸/超大网格保护，避免异常坐标造成超大碰撞循环。
- `markersInView` 增加投影有限值检查与 8192 网格上限，避免异常视图范围导致死循环。
- 面板顶栏、侧栏、详情先渲染；瓦片地图初始化改为后台加载。即使 Mapbox 瓦片网络很慢，也不会把整个面板留在黑屏等待状态。
- 初始化失败会 toast 提示，地点和点位仍可查看；不再静默卡住。

## 验证

- Tych Waterdeep：578 地点、8 区域、309 街道；
- 初始 Z13.3 能显示主路和区域名；
- Z14.9 / Z16 继续显示更多街道名；
- 阻断 `api.mapbox.com` 后，面板顶栏、侧栏、区域名和点位仍能显示，不再黑屏等待；
- `npm run check`、`npm run build` 通过；
- `dev.html` 和真实 SillyTavern 1.19.1 均无 `pageerror`。
