# 图层地图 0.10.0 · 导出地图包（Tavern Map 备份包）

> 日期：2026-11-28
> 范围：地图包管理里每个包可以导出成 `.zip`，可选带上笔记和全部个人修改；导入时认得这种包，按“保留本机 / 用包覆盖”合并。

## 为什么是“备份包”，不是还原成 Fandom / Map Genie 原文件

导入时插件把 Fandom `map.json` / Map Genie `mapdata.json` 换成自己的地图数据再保存，原始 JSON 不留（道路原始字段 0.9.0 起保留）。还原原文件只能靠猜字段，所以导出把插件里存的那份地图**原样**写出；字段与存储里的 `LayerMapPackage` 一一对应，没有新的数据结构。

## 包结构

```text
<地图名>.tavern-map.zip
├─ manifest.json        { "format": "tavern-map-backup", "version": 1, "name", "exportedAt", "parts", "data", "personal" }
├─ map-package.json     存储里的地图包原样；每个 Blob 换成 { "$tmlFile": "tavern-map-files/…", "type": "…" }
├─ personal.json        勾选带上的个人修改（键都相对这张地图，换设备后自动挂到新编号上）
└─ tavern-map-files/    地图包里所有 Blob：底图、瓦片、缩略图、Map Genie 图标……
```

- Blob 是遍历整个地图包找出来的，没有字段名单；以后地图包多了新的图片/文件字段，也会一起导出。
- ZIP 不压缩（瓦片本来就是 jpg/png），超过 65,535 个文件或 4 GB 时自动写 ZIP64。

## 导出（地图包管理 → 【导出】）

```text
导出地图包
地图本体（总会带上）：地点 2,501 · 区域 363 · 道路 518 · 瓦片 21,683 · 约 253 MB
名称、网格校准与距离换算、底图对齐都在地图本体里。
一起带上的个人修改：
☑ 笔记          地点、区域、道路笔记                                   3 条
☑ 改过的资料     改过的来源资料、手动添加的链接、已抓取的 Wiki 正文       没有（变灰）
☑ 图钉          移动过的位置、自定义图钉和撤销记录                      没有（变灰）
☑ “给 AI”勾选    地点、区域、道路的单独勾选                             没有（变灰）
☑ 收藏          这张地图里收藏的地点                                   没有（变灰）
☐ 当前聊天的“我”、视角和行程   这些按聊天保存，默认不带                 2 项
                                                  [取消] [导出 .zip]
```

| 勾选项 | 来自哪里 | 写进 personal.json |
| --- | --- | --- |
| 笔记 | 全局笔记 `layer:<包>:…`（地点、自定义图钉、`region:`、`road:`） | `notes` |
| 改过的资料 | 全局笔记 `layer-source:<包>:…`；`layer-linktext:<网址>`（只取这张地图里出现的网址）；当前聊天里手动加的链接和抓取文本（只取这张地图的地点） | `sources` `linkTexts` `links` `sourceLinkText` |
| 图钉 | `tavern-map:layer-pins:v1` 里这张地图 | `pins` |
| “给 AI”勾选 | `tavern-map:layer-place-ai:v1` 里这张地图（地点、`region:`、`road:`） | `aiFlags` |
| 收藏 | `tavern-map:favorites:v1` 里这张地图的收藏 | `favorites` |
| 当前聊天的“我”、视角和行程 | 当前聊天的位置、镜头、已完成行程 | `chat` |

不进包：扩展设置（AI 总开关等，不属于某一张地图）。

## 导入

导入流程不变：选 zip → 预览 → 确认。识别到 `manifest.json` 的 `format` 是 `tavern-map-backup` 时，不再解析 Fandom / Map Genie，直接按原样恢复地图，并在预览里多一节：

```text
个人修改
笔记 3 · 当前聊天的“我”、视角和行程 2
本机已有同一张地图时，个人修改怎么处理：
◉ 本机已有的保留，包里的只补本机没有的（不会丢任何东西）
○ 用包里的覆盖本机（两边都有的以包为准，本机独有的仍保留）
```

- 同一台设备：按原来的“同一编号 / 同一来源就更新”规则，更新原来那个地图包，不会多出一份。“保留”时本机改过的名称、网格、换过的底图也保留；“覆盖”时用包里的。
- 换设备：地图包沿用导出时的编号；个人修改挂到导入后的编号上。
- 两种方式都**不删除**本机独有的东西。
- 备份包已经带图标，导入时不再联网下载 Map Genie 图标。
- 包里缺文件（下载不完整）时直接报错，说缺几个文件，不导入残缺的地图。

## 验证

- `tests/layer-backup.test.mjs`：
  - 只收集这张地图的个人修改，统计数字正确；
  - 导出再读回来，地图包逐字段相同（包括 Blob 类型）；
  - 没勾的项不进包；
  - 新设备恢复后笔记、来源资料、链接正文、图钉、勾选、收藏、聊天数据都回来；
  - “保留 / 覆盖”两种规则；
  - 普通 zip 仍走原导入流程。
- `tests/layer-zip.test.mjs`：写出的 ZIP 能被读取器读回，中文文件名、CRC，以及 65,538 个文件时的 ZIP64。
- WebKit 实测（天际包，21,683 张瓦片）：
  - 导出用时 10.9 秒，得到 272 MB 的 zip；
  - 空白浏览器资料导入：读取 11.4 秒、写入 13.8 秒，地图、道路、区域、3 条笔记、“我”的位置都恢复；
  - 同一资料再导入：仍是 1 个地图包，笔记不变。
- 未验证：TauriTavern 里点“导出 .zip”能否正常弹出保存文件。
