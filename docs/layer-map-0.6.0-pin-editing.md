# 图层地图 0.6.0 · 图钉移动、自定义图钉与位置撤销

> 日期：2026-11-27  
> 范围：移动已有地点图钉、添加自己的图钉、链接/笔记、每个图钉最多 10 步位置撤销/重做。

## 数据边界

导入的地图包仍然只读，不会被改写。用户修改保存在独立的
`localStorage` 键 `tavern-map:layer-pins:v1` 中，按地图包 id 分区：

```text
{
  version: 1,
  maps: {
    "<packageId>": {
      overrides: { "<markerId>": { x, y } },
      customPins: [ ... ],
      history: {
        "<markerId>": { past: [...], future: [...] }
      }
    }
  }
}
```

因此：

- 关闭图层地图、刷新页面、切换聊天、切换地图包再回来，移动位置和自定义图钉都会恢复；
- 重新导入同 id 的地图包不会清掉用户图钉；
- 删除地图包时同时删除该包的图钉修改；
- 笔记仍使用已有的全局笔记 IndexedDB；自定义图钉的链接随图钉保存在地图级数据中。

## 移动已有图钉

1. 先点中一个地点图钉；
2. 直接按住它拖动，或点详情里的 **移动图钉** 再点新位置；
3. 松手/点击后立即保存。

瓦片地图用 MapLibre 的屏幕坐标换算；图片地图用画布反投影，两者都写回
0..1 的归一化坐标。移动后以下内容全部同步使用新坐标：

- 画布绘制、聚合、点击命中、标签；
- 搜索、分类计数；
- 附近地点、方向、距离；
- 当前地点、收藏、AI 上下文；
- 如果红色“我”原本就在这个图钉上，位置会一起跟过去。

导入图钉移动后会出现 **恢复原位**；恢复也是一次普通移动，可以再次撤销。

## Undo / Redo

每个图钉各自保存：

```text
past:   [旧位置, ...]  最多 10 个
future: [已撤销位置, ...] 最多 10 个
```

- 新移动把移动前坐标压入 `past`，并清空 `future`；
- 撤销把当前坐标压入 `future`，取出 `past` 最后一项；
- 重做反向操作；
- 拖动只在松手时记一步，拖动过程中不写历史；
- `Cmd/Ctrl+Z` 撤销，`Cmd/Ctrl+Shift+Z` 或 `Ctrl+Y` 重做；输入框内不拦截；
- 详情和顶部工具栏都有 `↶` / `↷`，只作用于当前选中的图钉。

撤销/重做只覆盖位置；改名、链接、笔记和自定义图钉的增删不属于位置历史。

## 自定义图钉

顶部 **＋ 图钉**：

1. 点按钮后在地图上点一下；
2. 自动创建分类为 **我的图钉** 的图钉；
3. 详情里可改名称、移动、收藏、添加链接、写来源资料和笔记；
4. 删除时会二次确认，并清理该图钉的笔记、来源资料和收藏。

自定义图钉会进入搜索、分类、附近地点、收藏和 AI 上下文；它在 AI 中出现的方式与普通地点一致。

- 关闭/刷新/切换地图包后自定义图钉和历史仍在；

- `npm run check`、`npm run build` 通过。

## 已知边界

- 桌面鼠标支持直接拖图钉；触屏设备可以直接点 **移动图钉** 再点新位置，不使用按住拖动；
- 自定义图钉目前没有独立图标选择器，统一使用“我的图钉”分类颜色和专用画布形状；
- 位置历史不覆盖笔记/链接编辑；
- 地图包更新若改变了 marker id，旧 id 的移动覆盖不会自动匹配到新 id。
