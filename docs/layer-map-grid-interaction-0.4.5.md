# 图层地图 0.4.5 · 网格缩放与在线高清瓦片

> 日期：2026-11-26  
> 范围：网格编辑布局、直接缩放、地图/网格缩放分离、Map Genie 在线高清瓦片。

## 1. 网格不再盖地图

- 桌面：网格面板放进右侧检查器，地图宽度和高度不被遮。
- 紧凑窗口/手机：面板进入底部，默认折叠为 44px 条；需要字段时展开，地图仍完整可见。
- 面板可收起，`完成` 后恢复地点详情。
- 地图在网格编辑时仍可拖动、滚轮/双指缩放、点地点。

## 2. 网格缩放

- 拖 `0,0`：移动网格原点。
- 拖右下角 `↘` 缩放点：放大/缩小格宽。
- 面板 `− / ＋` 和滑杆：精确缩放。
- `Alt+滚轮`：缩放网格；普通滚轮缩放地图。
- `X/Y 偏移` 可精确微调；方向键可后续补。
- 完成后网格配置保存到地图包。

## 3. Map Genie 在线高清

本地包只有 z9–z11 时：

```text
本地瓦片层（z9–z11，兜底）
  ↓ 高倍缩放
在线高清层（z12–16，来自 tiles.mapgenie.io 原始 pattern）
```

- 只在 Map Genie 包导入时读取到的 `pattern` 上启用。
- 本地层仍在下面兜底；网络失败时不会完全空白。
- 本地和在线层级在底部状态栏分别显示。
- 旧版本导入的包需要重新导入同一个包一次，才会写入 `remoteTemplate`。
