> 日期：2026-11-04　状态：**草案，待驾驶员评鉴，未定稿**。

## 0. 先说结果

1. **三种视图（标签嵌套 / 自制地图 / 第三方地图）用同一份数据**，区别只在"怎么摆出来"。数据里只有三样东西：**地点**（是什么、写了什么）、**画面**（一张可看的图或一个外链）、**摆放**（某地点在某画面上的位置）。
2. **"嵌套"不靠地图里嵌地图，靠地点树上给地点挂"细图"。** 点大图上的深水城 → 进入它挂着的城区图。没有细图就问一次"文字 / 上传 / 贴链接 / 稍后"，不强迫。
3. **第三方网页地图大多不能嵌、也读不到点位**（实测：World Anvil、Cartographia、Fandom 地图页都带 `X-Frame-Options: SAMEORIGIN`，即拒绝被别的网站嵌入）。所以第三方分两类：**瓦片型**（OSM、用户填的图源地址，我们能画点）和**网页型**（只能"打开"，不能在它上面标点）。
4. **"层"其实是三件事，必须拆开：** 下钻层级（世界→城→楼）、楼层（同一建筑的几层）、叠加层（势力、危险、笔记）。只有第三种才叫"图层开关"。
5. **图标由"图标包"决定，不由地点决定。** 地点只存"是什么"（酒馆、医院），中世纪包画啤酒杯、现代包画咖啡杯。
6. **操作动词统一，能力各图自己声明。** 做不了的按钮灰掉并写原因和补救办法（"这张图没设比例尺，无法量距离 → 设比例尺"）。
7. **VTT 不是地图的一种模式，是下钻最底下一级的"战术画面"**（有网格和棋子）。属于主项目 V2 的 A4，本模块只预留两个空字段，不做。

## 2. 数据模型（同构的核心，尽量小）

```
地点 Place            是什么、写了什么（不含"在哪"）
  id · 名称 · 类型kind(酒馆/城/医院…) · 上级地点 · 描述
  笔记[] ┬ 公开笔记(受"给AI"控制)
         └ 私密笔记(仅我，永不给AI)
  给AI: 不给 / 附近或被提到才给 / 常驻
  发现: 未知 / 听说 / 到过
  书签★: 只为快速找回，与AI无关
  关联: 人物 · 势力 · 任务 · wiki · 外链 · 参考图片
  细图: → 画面[]      ← 下钻入口（0 个或多个）

画面 Surface          一张可看的东西
  种类: 图片(自己上传/自己画) · 瓦片(OSM、用户填的图源地址)
        · 外链(网页型，只能打开)
  坐标系: 像素 / 经纬度 / 无
  比例尺?  网格?      ← 两个可空字段，VTT 将来用；现在不做
  楼层?               ← 同一栋建筑的几张画面各有楼层号（见第 10 节）

摆放 Placement        某地点在某画面上的位置
  地点id · 画面id · 点 / 线 / 区域
  （一个地点可以有多个摆放：世界图一个点，城图一块区域）
```

三种视图怎么对上：

| 视图 | 用到什么 | 备注 |
|---|---|---|
| ① 标签嵌套 | 只用地点树 + 参考图片 | 不需要画面，最轻，没图也能玩 |
| ② 自制地图 | 画面(图片) + 摆放 | 上传图后手动划区域、标地点、画道路；或直接导入做好的 |
| ③ 第三方地图 | 画面(瓦片) + 摆放；或画面(外链) | 外链无摆放，只有"打开"按钮 |

**同构带来的保证：** 同一批地点可以在三种视图间切换，不丢数据。在某张图上"还没摆放"的地点，进"未摆放托盘"，拖上去就摆好。

**迁移：** 试验版每条 `SavedPlace` → 一个地点（带笔记） + 一个摆放（在 OSM 瓦片画面上）。

## 4. 五个难题的回答

### 4.1 第三方只有世界图，细节怎么补？（下钻）

- 下钻挂在**地点**上，不挂在地图上：`深水城.细图 → 用户上传的城区图`。
- 在**可读的画面**（图片、瓦片）上，点深水城旁的"进入"即可。
- 在**网页型外链**上，我们点不到它里面的点；下钻入口在我们自己的树 / 搜索 / 列表里。要在图上点，只能由用户把截图上传成图片画面（个人使用；是否合规由用户自负，我们不分发）。
- 没有细图时的空状态，一次问清、可跳过：

```
 「深水城」还没有细图
 [写文字描述] [上传城区图] [贴一个链接] [先不管]
```

- 回退规则（不报错）：当前地点没有画面 → 用最近一级有画面的上级 → 再没有就只显示文字。
- 面包屑始终可见：`托瑞尔 › 剑湾 › 深水城 › 码头区 › 铁砧酒馆`。

### 4.2 图层之间太繁杂？

拆成三件事，各管各的：

| 叫法 | 是什么 | 怎么操作 |
|---|---|---|
| 下钻层级 | 世界→区域→城→区→建筑 | 地点树 + 进入 / 返回 |
| 楼层 | 同一建筑的几层，有高低顺序 | 楼层切换条；楼梯 / 电梯是连接 |
| 叠加层 | 势力、危险、事件、我的笔记 | "镜片"一次选一个 |

- **镜片 = 预设的一组叠加层**（默认 / 势力 / 危险 / 我的笔记）。第一版只给这几个预设，不做自由图层管理器。
- **层与层冲突：** 叠加层只属于一张画面，不跨画面；绘制顺序固定（底图 < 区域 < 路线 < 点 < 文字）；区域重叠按"优先级"排，"落在哪些区域"的判定返回全部命中，给 AI 的话是"最里层 + 也在…内"。
- 历史 / 平行世界（1920 年代等）：**第一版不做**；若做，是全局"时代"筛选，不是图层。

### 4.3 图标不统一（中世纪 vs 现代）？

- 地点存 **类型**（酒馆、医院、城堡），不存图案。
- 画面选 **图标包**（朴素圆点 / 中世纪 / 现代 / 科幻 / 武侠）；单个点可覆盖。
- 默认包 = 朴素圆点 + 首字，保证**永远不缺图标**。
- 图标素材沿用路线图已定的 game-icons.net（CC BY 3.0）；图标包的具体清单后定。

### 4.4 操作要不要统一？

**统一动词，各图声明能力。**

动词（用户能做的事）：看 · 选中 · 设为当前 · 前往 · 写笔记 · 给 AI · 加点 · 画区域 · 量距离 · 规划路线。

| 画面种类 | 能做 | 距离 / 路线怎么算 |
|---|---|---|
| 瓦片（真实世界） | 全部 | 真实路线 |
| 图片（自制） | 加点、画区域、量距离（需设比例尺） | 比例尺换算 |
| 地点树（无图） | 写笔记、给 AI、设为当前 | 树上边的"旅程耗时"（如 2 天） |
| 外链（网页型） | 只能打开 | 不可用；可手填"约 2 天" |

做不了的按钮**灰掉并写原因 + 补救**，不隐藏（隐藏会让人以为功能不存在）。

### 4.5 VTT 放哪？

- VTT = 下钻最底下一级："世界 → … → 建筑 → 楼层 → **战术画面（网格 + 棋子）**"。
- 它是一种带网格的图片画面，棋子 / 先攻 / 迷雾属于战斗模块（M7 / A4）。
- **本模块只做：** 画面上留 `比例尺`、`网格` 两个可空字段；地点的"细图"可以指向战术画面。其余一概不做。

## 5. 用户心理画像（快速版，假设）

**两个主画像**（沿用上一份文档的删减建议）：
- **边聊边玩的单人玩家**：想 1 分钟开跑，只要 AI 知道我在哪。
- **世界观作者 / 卡作者**：有托瑞尔这类大图，愿意花时间补细节，痛点是"大图没细图"。

**副画像**：现代 / 真实世界玩家（点是系统给的）；有网格需求的战术玩家（以后）。

**新增的心理张力：**

| 担心 | 表现 | 设计回应 |
|---|---|---|
| 换视图会丢数据 | "我先用文字，以后上传图，之前写的呢？" | 同构 + 未摆放托盘 |
| 选项太多不知选哪 | 起手面前有三种模式 | 起手四选一，任何时候能换 |
| 迷路 | 点进去几层不知道在哪 | 面包屑 + "回到上一层" |
| 外链会失效 | 站方改版、下线 | 存链接 + 标题 + 参考图 + 失效提示 |
| 地图做不了的事 | 点了路线没反应 | 灰掉 + 原因 + 补救 |
| 剧透与 AI 全知 | 怕 AI 说破没去过的地方 | 发现状态 + 私密笔记永不给 AI |

## 8. 三个界面草案

线框只画左边框（中文在等宽字体里无法对齐右边）。

### 草案 α：一棵树，三扇窗

```
┌─ 白港城 ──────────────── [树 | 图 | 外链] ── [＋新建地点]
│ 🔍 搜地点 / 笔记 / 人物
│ 面包屑: 托瑞尔 › 剑湾 › 白港城
│
│ ── 窗①：树（最轻，没图也能用）──
│ ▾ 白港城
│    铁砧酒馆   👣 📌 笔记2 ★
│    黑市       👂 💬 笔记1
│ ▸ 灰林镇
│
│ ── 窗②：图（自制或瓦片）──
│ [画面: 白港城图 ▾]  图标包[中世纪▾]  镜片[默认▾]
│  ▲黑市  📍铁砧酒馆  ◉你在这里
│  未摆放托盘: ○码头 ○旧灯塔  ← 拖到图上
│
│ ── 窗③：外链 ──
│ 托瑞尔大地图（外部网站） [打开] [贴参考图]
│ 该站不允许嵌入 · 点位无法读取
└─ AI 此刻看到: 当前地点 + 3 常驻 + 2 附近 ≈420字 [预览]
```

- **适合：** 三种需求都想要，数据只有一份。
- **缺点：** 三个窗口选项多，新手要先学"树 / 图 / 外链"。

### 草案 β：下钻阶梯（地图为主）

```
┌─ [🔍搜索]                       [镜片▾][图标包▾]
│ 托瑞尔 › 剑湾 › 深水城 ›        ← 面包屑，点任何一级回去
│ ┌──────────────────────────────┐   尺度
│ │  ▲黑市   ⚑红衣帮地盘          │   ┃ ● 世界
│ │       📍铁砧酒馆(进入▸)       │   ┃ ● 区域
│ │            ◉你在这里          │   ┃ ● 城   ← 你在这
│ └──────────────────────────────┘   ┃ ○ 建筑
│ 点「铁砧酒馆」→ 进入 ↓                ┃ ○ 楼层
│   没细图时: [写文字][上传图][贴链接][先不管]   ┃ ○ 战术(VTT·以后)
│ 灰掉的按钮: [量距离] 这张图没设比例尺 → [设比例尺]
└─ 底栏: AI 看到 当前地点 + 附近
```

- **适合：** 世界观作者，层级清晰，"我在哪一层"一眼可见。
- **缺点：** 以图为主，没图时空；手机上尺度条占地方。

### 草案 γ：聊天伴侣，自动选画面

```
│ AI: 你们穿过码头，往"渔夫之手"走去……
│ ┌────────────────────────────────────────────┐
│ │ 📍 当前: 港区·码头  [改] [↩撤销]            │
│ │ 🆕 AI 提到 3 个新地点:                      │
│ │    渔夫之手 · 老灯塔 · 灰鸥号               │
│ │    [加进地点册 ▾]  [都忽略]                 │
│ │ 🗺 自动显示: 港区图（最近一级有图的上级）   │
│ │    [展开成完整地图]                         │
│ └────────────────────────────────────────────┘
│ [输入框…………………………………………] [发送]
```

- **适合：** 单人边聊边玩。
- **优点：** 不用选视图，系统自动用"最近有图的画面"，没图就只显示文字。
- **缺点：** 要识别 AI 文字里的地名，有误判，需抽检。

### 共用件

起手四选一（空地图时）：

```
 开始一张地图：
 [📝 先写地点（文字）]  [🖼 上传一张图]  [🌍 真实世界]  [🔗 贴一个链接]
 ← 任何时候都能再加别的画面，数据不丢
```

### 10.1 参考：Mappedin 霍格沃茨城堡图

- Mappedin 托管，底图楼层平面为粉丝作品；约 10 层，3D 显示，有地点标注。
- 页面带 `X-Frame-Options: SAMEORIGIN`，不能嵌入；用其 SDK 做自己的地图需要 Pro 授权（付费）。**结论：只能当外链，不能接入；借它的设计，不用它的系统。**
- 免费开源可选：`maplibre-gl-indoor`（MIT）、`map-gl-indoor`，基于 OSM 室内标签 `level=*`。**未验证**当前维护状态与楼层选择行为，选型前要看仓库。

### 10.2 "立体"拆成三件事

| 种类 | 处理 |
|---|---|
| 多楼层（每层一张 2D 图） | **画面加"楼层"字段 + 新增"连接"** |
| 3D 外观（墙体挤出） | 只是显示效果，第一版不做 |
| 不对齐的立体（会动的楼梯、暗道、塔楼） | 靠"连接"表达，层与层不需要上下对齐 |

### 10.3 数据只补两样

```
画面.楼层?   同一栋建筑（一个地点）下并列的几张画面，各有楼层号
连接 Connection
  两端摆放(各在不同楼层) · 类型(楼梯/电梯/梯子/暗道/传送)
  耗时(可手填"约8分钟") · 状态(可用/锁住/隐藏)
  发现状态: 未知的连接不给 AI，不在玩家视图显示
```

- 跨楼层路线 = 沿"连接"走的图算法（与第 4.4 节"树上边的旅程耗时"同一引擎），不是真实几何路线。
- 给 AI 的文字带楼层，如"霍格沃茨城堡·7 楼·有求必应室"。
- 其他楼层可选"淡显"；楼层条与"尺度条"是两条独立的轴。
