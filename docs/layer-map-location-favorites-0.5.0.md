# 图层地图 0.5.0 · 图章、半径、收藏与 AI 设置

> 日期：2026-11-26  
> 范围：点击地点状态、图章“我”、附近半径、收藏库、所在地点/周围地点/收藏地点 AI 设置。

## 1. 点击地点

- 点地点只打开详情：原点变大、显示名字；即使标签图层关闭，选中地点名字仍显示。
- 收藏按钮：`☆ → ★`。
- 点开地点不改变 AI；只有把“我”移动到这里才算“所在地点”。

## 2. 图章“我”

- 圆形图章，可拖动。
- 拖动时地图不跟手；松手才提交。
- 靠近地点自动吸附；`Alt/⌥` 可自由拖动。
- 工具栏只保留 `◎ 回到我`；不再有重复的 `◉ 我` 按钮。
- 位置卡显示坐标、区域和附近半径。

## 3. 附近范围

- 圆围绕“我”的图章。
- 图层地图：有网格时用格，没网格时用地图宽度百分比；现实地图用米。
- `附近半径` 滑杆在位置卡中调整；AI 只取圈内地点。
- 地图上的圈、右侧附近列表、AI 的 Nearby 使用同一半径。

## 4. 收藏

- 左侧 `[图层] [收藏]` 页签。
- 全局收藏库，按地图包分组；换聊天不丢。
- 收藏只改变收藏库；是否进入 AI 由全局 `收藏地点` 设置决定。
- 收藏地点发给 AI 不设数量上限。

## 5. 全局设置

总开关：

```text
[x] 启用 AI 注入
地图上下文：(•) 图层地图 ( ) 现实地图 ( ) 不注入
```

图层地图三块：

- 所在地点：来源、Wiki、笔记、名称/类型、坐标/区域。
- 周围地点：启用、类型、方位/距离、XY、笔记、最多数量。
- 收藏地点：启用、类型、区域/坐标、笔记、来源、Wiki；无数量上限。

现实地图与图层地图分开；不再每链接勾“加入 AI/常驻显示”。

## 6. AI 输出

```text
[SCENE MAP]
Map: ...
My position: ...
Current place: ... (只有图章吸附到地点时)
Nearby (within radius):
...
Favorites:
...
Source material (my place):
Wiki text (my place):
[/SCENE MAP]
```

点开但没拖过去的点不会进入 `Source material` 或 `Wiki text`，最多作为 Nearby/Favorites 出现。

## 7. 验证

- dev/真实 ST：点地点放大+标签、星标收藏、收藏页签。
- 图章拖动到地点/空地；半径圈和 Nearby 同步。
- 设置三块分别控制 AI；收藏无数量上限。
- `npm run check`、`npm run build`、Impeccable detector 通过。
