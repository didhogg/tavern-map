# 图层地图 0.9.0 · 道路点选、道路详情、道路笔记与来源资料进入 AI

> 日期：2026-11-28
> 范围：点选道路高亮、右栏道路详情（来源资料 + 道路笔记）、道路笔记和来源资料的 AI 开关；导入时保留道路的原始字段。

## 一条“路”是什么

- 同名同类型的所有线段算一条路（数据常把一条路切成好几段）；没有名字的线段各自算一条。
- 高亮、笔记、“给 AI”勾选、AI 去重都按这条规则。

## 点选与高亮

- 工具栏 **道路** 打开时，点在道路线附近几像素内即选中这条路；地点图钉和聚合圈优先。
- 规划行程、放“我”、放图钉、移动图钉时点地图仍是原来的作用。
- 附近列表里的道路行、行程展开后的“在 / 换到 某路”和范围内道路行，点一下也会选中并居中这条路。
- 选中的路加粗发亮（道路层关闭时也画），同名的几段一起亮。

## 右栏道路详情

```text
道路
河木镇 – 煤块矿场 大路
Main · 1 段 · 全长 4.7% 地图
[居中]
▼ 来源资料（随道路显示）                ☑ 给 AI
   fid        skyrim-road-62
   Name       河木镇 – 煤块矿场 大路
   NameEn     Riverwood – Embershard
   Type       Main
   From       河木镇
   To         煤块矿场
   generated  true
道路笔记                                ☑ 给 AI
[ 写一段道路笔记… ]
```

- 来源资料：地图数据里这条路的全部原始字段，按原顺序原样显示，只读。同一条路的几段字段不同时，按不同的字段组分组显示。
- 0.9.0 之前导入的地图包没有保存原始字段，只显示路名和类型，并提示重新导入地图包。
- 道路笔记按地图包保存（和地点笔记、区域笔记同一存储），不修改导入包。

## AI 设置（图层地图 · 道路笔记与来源资料）

```text
☑ 当前位置附近道路的笔记（在路上的那条和附近列表里的道路）
☑ 行程当前段道路的笔记
☐ 行程所有段道路的笔记
☐ 道路来源资料一起发给 AI（只发上面勾选范围内的道路）
```

- 一段行程的道路 = 这一段实际走过的路 + 范围内列出的路（与行程列表一致，受“显示沿途地点和道路 / 只显示当前段”开关影响）。
- 当前段：在路线上为所在段；还没出发为第 1 段；到达终点后没有。行程本身关闭“发给 AI”时，行程段的道路也不发。
- 每条路只出现一次，方括号写出被带上的原因：`near me`、`current leg`、`leg 2`。
- 每条路详情里，笔记和来源资料各有一个“给 AI”，可单独取消（默认勾选；对应全局开关都关闭时变灰）。
- 来源资料全局开关默认关闭：附近道路常有 8 条，每条 7 个字段，默认全发会让场景块很长。

```text
Road notes and source:
- 河木镇 – 煤块矿场 大路 (Main) [near me]: 这条路常有帝国巡逻
  Source: fid=skyrim-road-62; Name=河木镇 – 煤块矿场 大路; NameEn=Riverwood – Embershard; Type=Main; From=河木镇; To=煤块矿场; generated=true
- 白漫城 – 龙临堡 小径 (Path) [current leg]: ……
```

没有来源资料时标题为 `Road notes:`。

## 数据边界

- 导入时每条道路多保存一份原始字段（`properties`，键值按原顺序）；地图包格式不变。
- 聊天状态多保存当前选中的道路（`selectedRoadKey`）。
- 笔记键：`layer:<地图包>:road:<道路键>`；“给 AI”排除项与地点同一存储，键 `road:<道路键>`。

## 验证

- 单元测试：导入保留原始字段、AI 文本的道路笔记 / 来源格式与去空。
- WebKit（天际地图包重新导入）：附近列表点选道路 → 右栏显示 7 个原始字段；地图上点道路选中同一条路；写笔记 + 勾选来源 → AI 出现 `Road notes and source`，每条路一次。
- `npm run check`、`npm run build` 通过。

## 0.9.1 补充：“给 AI”勾选所见即所得

区域笔记、道路笔记、道路来源资料的“给 AI”勾选框按同一规则工作（地点的三个勾选框保持 0.6.1 的“只用来取消”规则不变）：

```text
在自动范围内（我所在的区域及上级 / 附近道路 / 勾选的行程段道路）：默认勾选，取消后不发
在自动范围外（别的区域、别处的道路）：默认不勾，勾上后也发
  AI：Other area note (裂谷城 Riften): …
      - 某路 (Main) [pinned]: …
```

勾选状态与自动规则一致时不保存，回到自动；只有与自动规则不同的选择才保存（与地点开关同一存储）。
