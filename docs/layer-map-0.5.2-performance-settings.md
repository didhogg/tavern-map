# 图层地图 0.5.2 · 设置可读性与地图性能

> 日期：2026-11-26  
> 范围：扩展设置配色、密集点位聚合、视口裁剪说明、网格校准手柄位置。

## 1. 扩展设置：白底黑字

`#tm-settings` 现在强制使用浅色设置面板和黑色文字：

- 标题、说明、checkbox 标签、输入框、按钮统一黑色；
- 数字输入/下拉框为白底黑字；
- 分组标题不再使用浅金色或灰色；
- 地图窗口本身仍保持深色，不受影响。

## 2. 密集点位地图性能

图层地图（图片地图和瓦片地图）现在分层绘制：

1. **空间索引**：按 `MARKER_INDEX_CELL` 建立桶，先只取视口附近点位。
2. **视口裁剪**：视口外点位不进入绘制和命中循环。
3. **屏幕网格聚合**：点位超过 500 个，且缩放低于阈值时，按 36px 屏幕网格聚合。
4. **数量簇**：同格点位绘制成一个金色圆，显示数量；点击数量簇会放大到该区域。
5. **逐点绘制**：放大后或点位较少时恢复分类颜色/原始图标，选中点位始终单独绘制，不受聚合隐藏。
6. **图标缓存**：Map Genie 原始分类图标按分类缓存为小 Canvas，避免每帧重新解析字体。

阈值：

- 图片地图：缩放低于 1.55× 聚合；
- 瓦片地图：缩放低于 z10.8 聚合；
- 少于 500 个可见点位不聚合。

瓦片底图仍由 MapLibre 做标准栅格瓦片加载/缓存；本次不改瓦片协议，只减少叠加层每帧的绘制量。图片地图仍使用渐进大图加载。

## 3. 网格校准手柄居中

之前新建默认网格的 `0,0` 使用地图左上角，缩放柄使用 `origin + 3 格`，在视口外或最角落，不方便对齐。

现在：

- 新网格默认 `originX = 当前视野中心`，`originY = 当前视野中心`；
- `0,0` 手柄出现在地图中心；
- 拉伸柄出现在中心网格的右下 3×3 位置；
- 打开旧版默认网格时，如果它仍是左上角 + 默认格宽 + 未显示状态，自动迁移到当前视野中心；
- 用户手动移动过的网格不会被迁移。

## 4. 验证

- dev：点击数量簇会放大；
- dev：设置面板白底黑字；
- dev：网格 `0,0` 和拉伸柄位于地图中心区域；
- `npm run check`、`npm run build`。
