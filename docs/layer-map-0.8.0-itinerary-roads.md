## 规划时选择每段是否贴合道路

```text
行程编辑                         [撤销上一站][完成][取消][收起]
下一段：[贴合道路 ●]   沿途范围 ├────●──────┤ ±1.6 格（8.0% 地图宽）
```

- **贴合道路** 是开关，亮着时下一次点地图加的这一段沿道路走；再点一下熄灭，下一段就是直线。开关保持到再次点击。
- 行程列表每一段右侧有 **沿路 ●/○**，已经加好的段（编辑中或已完成的行程）也能单独切换。
- 地图没有道路数据时，贴合按钮和每段的沿路按钮不出现或变灰。

### 贴合道路怎么走

1. 从这一段的起点直线走到离它最近的道路；
2. 沿道路网走最短的路；
3. 从离终点最近的道路上的点直线走到终点。

两头的道路不连在一起时，能沿路的部分照样沿路，两片路网之间最近的缺口用直线补上并标注“无路相连”。

道路网的规则：每个道路折点都是一个连接点；同一位置的折点相连；道路端点紧贴另一条路的中段（T 字路口但没有共用折点）时自动接上。全部按地图数据的几何位置计算，不按名字匹配。

### 显示

- 地图：沿路部分实线，路外直线部分细虚线；换路或离开道路的地方画 ◆。
- 列表展开一段：
  ```text
  ┄ 直线 0.3 格，走到路上
  ═ 在 河木镇 – 白漫城 大路（Main） 上 · 3.1 格
  ◆ 换到 白漫城 – 龙临堡 小径（Path） · 1.0 格
  ┄ 直线 0.3 格，到经停点 2
  ━ 河木镇 – 溪木镇 小径（Path） · 距本段 0.8 格     ← 范围内其他道路
  沉睡巨人旅店 · 门                                   ← 沿途地点
  ```
  同名同类型的相邻路段合并成一条；道路名为空时显示“无名道路”。
- 距离、当前段百分比、剩余距离、沿途地点的“沿程”都按实际走的折线计算。
- 红色“我”沿线拖动时吸附到实际路线；当前在路上时显示“在 某某道路 上”。

## 沿途范围（全局一个）

- 设置页“图层地图 · 行程 → 沿途范围（% 地图宽）”、行程面板的滑条、地图上的范围拉手是同一个数。
- 规划或展开行程列表时，地图上画出范围带（淡色填充 + 金色边线）；拉手在路线外侧（避开行程面板），按住往外拖变宽、往里拖变窄，松手保存到全局设置。
- 滑条按对数刻度，范围 0.1%–40% 地图宽。
- 沿途地点、范围内道路、AI 输出在松手（或滑条松开）后更新。
- “% 地图”统一按地图宽度计算（Y 方向按同一比例换算），与附近半径一致。

## 范围内道路

- 每段列出范围带里的其他道路（不含这一段正在走的路），每个路名一条，近的在前，和路线相交或相接的写“与本段相接”。
- 数量与沿途地点共用“每段最多显示”的上限。

## 两个新的全局开关

```text
☑ 显示沿途地点和道路（列表、地图金圈、AI 一起）
☐ 只显示当前所在段的沿途地点和道路
```

- 关闭第一个：列表、地图金圈和 AI 都不再列沿途地点和范围内道路（距离和贴合路线照常）。
- 勾第二个：只给当前所在段；还没上路按第 1 段；到达终点后不再列。规划（编辑）中仍显示所有段，方便调整。

## 附近列表里的道路

- “我”的附近半径内的道路列在附近列表最上面，每个路名一条，显示类型、距离、方向；在路上显示“就在路上”。
- 数量受“最多地点数”限制；和附近地点一起受“半径圈内地点进入 AI”开关控制。

## 数据边界

- 地图包与格式不变。
- 行程站点新增可选 `snapRoad: true`，表示“到这一站的这一段沿道路走”。路线不存储，每次按道路现算，所以挪动站点、地点移动后路线跟着重算。
- 旧行程打开后每段都是直线。

## 验证

- 单元测试：道路网连接、T 字路口、不连通直线补、最短路选择、无道路、范围内道路、折线投影、AI 文本；天际地图包风舵城 → 马卡斯城全程沿路（中间没有直线缺口）。

- `npm run check`、`npm run build` 通过。

## 已知边界

- 不做路线自动排序、步行/骑马时间。
- 天际地图包的道路按两端地点命名，长路线会列出很多段“换到 …”，这是数据本身的分段。
