# 图层地图模式 · ASCII 界面与交互预览

> 日期：2026-11-25  
> 状态：**核心界面与交互已实现；绘制、网格、路线仍属后续**。  
> 样本：  
> - Map Genie / Leonida：瓦片地图，3,126 个地点、112 个区域、99 个分类、Day/Night 两套瓦片。  
> - Fandom / 深水城：图片地图，1,016 个地点、17 个分类、3000×4524 逻辑画布、`origin=bottom-left`。  
> 适用：Tavern Map 的 `现实地图 / 图层地图` 双模式，不把图层地图塞进 OSM，也不使用 iframe。

---

## 0. 一页结论

图层地图不是“另一张在线地图”，而是一个 **本地地图包查看器**：

```text
一张底图（图片 或 瓦片金字塔）
  + 地点 marker
  + 区域 polygon（可选）
  + 分类 / 分组过滤
  + 地点笔记与多来源链接
  + 当前地点 / 当前区域 → 下一次 AI 生成
```

界面分两层：

```text
宽工作台（桌面，推荐）
  左：地图包 + 分类过滤
  中：地图视口
  右：地点详情 / 笔记 / 链接
  下：地图状态 + AI 上下文状态

紧凑面板（聊天侧栏 / 手机）
  上：地图
  下：地点 / 图层 / 搜索 / AI 四个标签页
```

核心原则：

1. **地图是背景，地点是主角。** 点 marker 不是看坐标，是打开地点卡。
2. **来源内容与我的笔记分开。** 导入内容只读；笔记永不覆盖、不因取消收藏而丢。
3. **图层开关只影响“看见什么”，不影响数据。** 隐藏分类不会删除 marker 或笔记。
4. **不伪造距离和路线。** 没校准就写“未校准”，没有路网就不显示真实路线。
5. **AI 只读当前状态。** “实时”指下一次生成前状态已更新，不是流式注入正在生成的回复。

推荐桌面尺寸：

```text
宽：min(1180px, 96vw)
高：min(760px, 88vh)
左栏：232px（可折叠到 0）
右栏：320px（无选中时 0 或收起为窄条）
顶栏：44px
状态栏：28px
地图最小高度：360px
```

紧凑模式：

```text
宽：现有 430px 面板
高：地图 220–260px + 下方标签页
```

> ASCII 图的宽度不是像素规格；中文按双宽字体阅读。实际布局用 CSS Grid，不照抄字符对齐。

规则：

- 区域命中按“最内层 / 面积最小”优先；详情返回全部包含的区域。

- 区域笔记与地点笔记分开保存。
- Fandom 的 `Wards/Neighborhoods` 是点，不是面；界面必须写“区域点”，不要画成假多边形。

### 3.2 低缩放与聚合

```text
Z 8–10：区域面 + 聚合点
  ● 128    ● 42    ● 7

Z 11–12：分类聚合 + 区域标签
  ● 24 ATM   ● 8 Gym

Z 13+：单点 marker
  ● ATM   ● Zenith   ● The Vault

Z 15+：显示名称标签
```

规则：

- 聚合点点击 → 放大到能分开的级别，或展开列表。
- 标签在低缩放默认关闭；`标签` 开关可强制显示，但会限制数量。
- 选中地点始终显示，不受聚合影响。

## 4. 搜索

搜索是本地的，不调用 Photon，也不访问外部地理编码。

```text
┌ 🔍 搜 “yawning” ───────────────────────────────────────────┐
│ 地点 (2)                                                   │
│  ● Yawning Portal            Inn · Dock Ward       [定位]  │
│  ● Yawning Portal Alley      Street · Dock Ward    [定位]  │
│                                                            │
│ 分类 (1)                                                   │
│  ▸ Inns · 37 个地点                              [只看]    │
│                                                            │
│ 区域 (1)                                                   │
│  ▸ Dock Ward · 区域点 · 86 个地点                 [只看]    │
│                                                            │
│ 笔记 (1)                                                   │
│  ● Yawning Portal · “井口通往…”                  [打开]    │
│                                                            │
│ 当前有 2 个结果被图层隐藏                        [显示全部] │
└────────────────────────────────────────────────────────────┘
```

搜索规则：

- 匹配：名称、分类、区域、笔记、链接标题；大小写不敏感。
- 结果分组：地点 / 分类 / 区域 / 笔记。
- 隐藏分类中的结果仍可出现，但标记“被图层隐藏”，提供 `[显示]`。
- 键盘：`↑/↓` 选择，`Enter` 打开，`Esc` 关闭。
- 搜索“街道”时，Street 点与 Street 线都算；结果里标明“点/线”。
- 没有结果时给下一步，不只显示空列表：

```text
没有找到 “xxx”
[清除搜索]  [搜索全部地图包]  [检查隐藏图层]
```

链接状态：

```text

```

规则：

- 抓取只读正文文本，不执行页面脚本。
- CORS 失败不自动走公共代理；提供 `[打开原页]` 与 `[粘贴正文]`。
- Wikipedia 走现有 MediaWiki API；支持语言切换与缓存。
- Map Genie 页面只作为外链来源，不在插件内实时抓取。
- 来源正文进入 `sourceExcerpt`，与 `placeNote` 分开；默认不自动进 AI。

| 操作 | 结果 | 反馈 | 失败/边界 |
|---|---|---|---|
| 单击 marker | 选中地点，右栏打开 | 选中环、状态栏名称 | 分类隐藏时提示 |
| 双击 marker | 放大并居中 | 平滑动画 | 已最大缩放则只居中 |
| 单击区域 | 选中区域 | 区域高亮、区域卡 | 重叠时取最内层 |

| 滚轮 | 以鼠标为中心缩放 | 缩放百分比 | 最小/最大限制 |
| 搜索 | 本地结果分组 | 结果数、隐藏提示 | 无结果给补救 |
| 分类开关 | 隐藏/显示 marker | 计数更新 | 不影响笔记 |
| Day/Night | 切换底图 | 瓦片淡入 | 缺瓦片用占位 |
| 设为当前 | 当前地点变化 | 图钉变“当前”样式 | 区域也可设为当前 |
| 写笔记 | 自动保存 | “已保存 · N 字” | 失败提示重试 |
| 添加链接 | 新链接行 | 状态“未抓取” | URL 非法时阻止 |
| 抓取链接 | 正文摘要 | “已抓取 · N 字” | CORS/登录失败 |
| 画点 | 新本地地点 | 小表单 | 空名称用“未命名地点” |
| 画区 | 新区域 | 顶点手柄 | 少于 3 点不能闭合 |
| 测量 | 折线距离 | 总长/分段 | 未校准只显示 px |
| 导入 | 新地图包 | 进度/结果 | 文件错误可返回 |
| 切换聊天 | 恢复该聊天状态 | 地图包/视角/笔记 | 地图包缺失提示重选 |

## 14. 两个样本的字段映射

### 14.1 Map Genie / Leonida

```text
mapData.map.title                 → package.name
mapData.mapConfig.tile_sets[]     → baseLayers Day / Night
  .pattern                        → tiles/{z}/{y}/{x}.jpg
  .min_zoom / .max_zoom           → zoom range
  .bounds                         → tile bounds
mapData.groups[]                  → category groups
mapData.categories{}              → categories
mapData.locations[]               → markers
  .id                             → sourceId
  .title                          → sourceName
  .description                    → sourceDescription
  .latitude / .longitude          → placement
  .category_id                    → category
  .region_id                      → region
mapData.regions[]                 → areas
  .features[].geometry            → Polygon / MultiPolygon
mapData.mapConfig.start_lat/lng   → default view
```

注意：

- 瓦片 URL 是 `{z}/{y}/{x}`，不是 `{z}/{x}/{y}`。
- 地点坐标是地图坐标，不是现实世界 GPS。
- `regions` 是 Polygon；不要当点。
- 区域和地点都有 `sourceId`，可增量更新。

  .coordinateOrder   → xy

  .categories[]      → 17 个分类
  .markers[]         → 1,016 个点
    .id              → sourceId
    .position[0]     → x
    .position[1]     → y
    .categoryId      → 分类
    .popup.title     → sourceName
    .popup.description → sourceDescription

## 15. 性能与实现边界

已实现的性能策略（不截断源数据）：

```text
图片 / 瓦片
  → 单 Canvas 2D 视口，底图、区域、marker、标签统一绘制
  → 所有导入瓦片和地点保留，不做数量/文件大小/正文长度截断
  → 瓦片按视口只加载可见块，加载并发上限 8，其余排队
  → 已解码瓦片 LRU 缓存；只回收内存中的图像对象，源瓦片和地图包数据不动
  → 拖动/滚轮/缩放合并到 requestAnimationFrame，一帧只重绘一次

地点
  → 归一化坐标 + 0.025 网格空间索引
  → 每帧只遍历视口内 marker，不再全量遍历
  → 点击命中同样先查视口索引
  → 标签按 48px 屏幕网格避让；被遮挡的标签不删除数据，放大后重新出现

区域
  → 区域面使用 Canvas path，按视口绘制
  → 点选区域用 point-in-polygon，取最内层/面积最小区域
```

仍然不做：

```text
→ MapLibre 3D / 地形 / 倾斜
→ 从截图自动识别道路
→ 把 Map Genie 数据内置进仓库
→ 公共抓取代理
→ 绘制/网格/路线（后续）
```

数据约束：

```text
不限制：瓦片数量、瓦片文件夹大小、地点数量、区域数量、笔记长度、导入描述长度、搜索返回数量
只限制：内存中的已解码瓦片缓存（可重新读取源文件）
```
只限制：内存中的已解码瓦片缓存（可重新读取源文件）
```

参考的本地项目：

```text
Atlas VTT
  → RenderScheduler：只在场景变化时渲染，避免空闲帧持续重绘
  → Pixi viewport：按视口处理 marker/图层
  → mosaicCanvas / tile cache：大图分层与解码缓存思路

本项目没有复制 Atlas 的 AGPL 代码；只借鉴“按变化渲染、按视口裁剪、解码缓存与源数据分离”的结构。
```

数据存储：

```text
extensionSettings
  → 地图包元数据、当前地图包、UI 偏好

IndexedDB
  → 地点 JSON、区域 GeoJSON、分类、搜索索引

本地文件 / 用户选择的目录
  → 底图、瓦片

聊天状态
  → 当前地图包 id、视角、选中地点、当前地点、隐藏分类、笔记、AI 勾选
```

不建议把 5.4MB JSON 和瓦片塞进 `localStorage`。
