# 图层地图 0.6.1 · 地点级来源 / Wiki / 笔记 AI 开关

> 日期：2026-11-27  
> 范围：每个图层地点的来源资料、Wiki 正文和笔记，各自增加“给 AI”勾选框。

## 交互

地点详情中三处各自有一个 **给 AI** 勾选框：

- **来源资料（随地点显示）**：控制这个地点的来源资料；
- **链接来源**：控制这个地点导入链接和用户链接里已缓存的 Wiki/正文；
- **我的笔记**：控制这个地点的笔记。

规则：

- 相应内容类的全局开关开启时，地点默认勾选；
- 点击一次取消勾选，只影响这一个地点的这一类内容；
- 再点击一次恢复勾选，回到默认状态；
- 没有全局开关能让这一类内容进入 AI 时，勾选框禁用并保持未勾选；
- 取消勾选不会隐藏详情里的原文，只从 AI 上下文中移除。

## 全局开关的含义

地点勾选框的可用状态由当前、附近和收藏三类全局设置共同决定，但读取仍由原来的全局开关控制：

| 内容 | 可能来自 |
| --- | --- |
| 来源资料 | 所在地点来源 / 附近附带来源 / 收藏附带来源 |
| Wiki 正文 | 所在地点 Wiki / 附近附带 Wiki / 收藏附带 Wiki |
| 笔记 | 所在地点笔记 / 附近附带笔记 / 收藏附带笔记 |

只要其中至少一个有意义的开关打开，地点级勾选框就可用。例如：

- 所在地点 Wiki 关闭，但附近 Wiki 打开：地点勾选框仍可用于取消该地点在附近结果里的 Wiki；
- 收藏总开关关闭：收藏附带的子开关不会单独让勾选框变为可用；
- 全部相关开关关闭：勾选框禁用，并提示“没有开启…的全局 AI 开关”。

地点取消勾选后，**当前地点、附近地点和收藏**中该地点的这类内容都不会再进入 AI。  
全局总开关（例如“把收藏地点发给 AI”）仍然优先；地点勾选框只是进一步收窄。

## 保存

地点级开关按地图包保存在：

```text
localStorage["tavern-map:layer-place-ai:v1"]
```

结构：

```json
{
  "version": 1,
  "maps": {
    "<packageId>": {
      "<markerId>": {
        "source": false,
        "wiki": false,
        "note": false
      }
    }
  }
}
```

只保存显式的 `false` 排除项；没有记录的内容类默认开启。因此：

- 关闭 / 刷新 / 切换聊天后恢复；
- 切换地图包再回来恢复；
- 重新导入同 id 的地图包仍保留；
- 删除地图包时清理；
- 删除自定义图钉时清理该图钉的开关；
- 不会修改导入的地图包。

## 验证

- 默认全局来源、笔记开启时，地点详情对应勾选框默认勾选；
- 全局 Wiki 关闭时，Wiki 勾选框禁用；开启后默认勾选；
- 取消来源 / 笔记后，`Current place source` / `Current place note` 消失；
- 取消 Wiki 后，`Current place wiki` 消失；
- 取消一个地点的三部分内容后，该地点在附近地点里的 `Source material` / `Wiki text` / note 一并消失；
- 收藏内容遵循同样的地点级排除；
- 其他地点不受影响；
- 刷新、切换地图包后排除状态保留；
- 390×844 紧凑布局下三个勾选框不溢出；
- `npm run check`、`npm run build` 通过。

## 已知边界

- 当前实现针对图层地图地点；现实地图的地点详情没有“来源资料”分区，保持原设置；
- Wiki 勾选框控制该地点的全部链接正文，不拆分到单条链接；
- 地点级勾选框只管 AI 发送，不改变本地编辑和显示；
- 每个地点独立保存三类排除项，不做批量 UI。
